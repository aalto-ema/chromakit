# Security reporting

ChromaKit is an early local research application, currently version 0.1.0. There
are no supported stable releases or response-time guarantees yet. Fixes target the
current development version; older copies may require updating.

For a suspected vulnerability, use the repository's **Security → Report a
vulnerability** option if private vulnerability reporting is enabled. If that
option is unavailable, open a minimal issue requesting a private reporting channel,
without exploit details, sensitive files or credentials. A maintainer must arrange
that channel before receiving sensitive evidence. Do not post laboratory data,
personal information, passwords or working exploit payloads in public issues.

A useful private report describes the affected version, platform, impact and a
small synthetic reproduction. Ordinary numerical or UI bugs belong in the bug
tracker unless they expose a security issue.
